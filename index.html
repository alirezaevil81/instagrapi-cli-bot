instagrapi-cli-bot

ربات خط فرمان تعاملی اینستاگرام با فرم‌های هوشمند و خروجی‌های مدرن ترمینال

👥 ربات تعامل با فالووینگ‌ها

پیمایش فالووینگ‌ها، مشاهده پست‌ها، لایک خودکار و ارسال کامنت‌های دلخواه با تاخیر زمانی امن.

uv run followers-bot
  • ورود امن با Password مخفی، تشخیص هوشمند 2FA و سشن کش
  • تنظیم تعاملی تاخیرها با Questionary
  • سیستم لاگینگ پیشرفته Rich Console.log با زمان و مبدأ فایل
🎯 ربات استخراج لایک‌کننده‌ها

دریافت لینک پست‌های هدف، استخراج لایک‌کننده‌ها، فیلتر حساب‌های خصوصی و تعامل مرحله‌ای.

uv run post-likers-bot
  • نمایش جدول مدرن کاربران با Rich Table
  • فیلتر خودکار پیج‌های خصوصی و فالووینگ‌ها
  • ذخیره و بازیابی مرحله‌ای با صف Pickle و ثبت لاگ هوشمند
🪵 قابلیت Rich Console.log (ثبت لاگ با زمان، فایل مبدأ و هایلایت نحوی)

سیستم لاگ با بهره‌گیری از متد console.log() کتابخانه Rich، امکانات زیر را به همراه دارد:

  • ستون زمان دقیق ثبت هر پیام لاگ (timestamp column)
  • ستون نام فایل و شماره خط فراخواننده (file:line column مانند bot.py:57)
  • هایلایت خودکار ساختارهای پایتون (Syntax Highlighting) برای اعداد، رشته‌ها و وضعیت‌ها
  • چاپ ساخت‌یافته و زیبای کالکشن‌ها (Pretty printing برای dict و list با log_data)

⚡ راه‌اندازی آسان و اجرای یکپارچه با src/main.py

پروژه دارای فایل استاندارد pyproject.toml و نقطه ورود یکتای src/main.py است:

# ۱. همگام‌سازی و نصب پکیج‌ها با uv: uv sync # ۲. اجرای منوی تعاملی ربات: uv run instabot # یا: uv run python -m src.main # (یا با پایتون استاندارد: python -m src.main)
📁 ساختار خالص فایل‌های پروژه (Pure src-layout)
├── src/ │ ├── __init__.py │ ├── main.py # نقطه ورود اصلی و منوی تعاملی ربات‌ها (Interactive CLI Hub) │ ├── bot/ │ │ ├── __init__.py │ │ ├── bot.py # کلاینت لاگین هوشمند، ۲FA و توابع اینستاگرام │ │ ├── color_text.py # مدیریت رنگ‌ها و استایل‌های بومی Rich │ │ ├── config.py # کامنت‌ها و پیام‌های پیش‌فرض │ │ └── utils.py # جدول‌های Rich، لاگر با ساعت ایران و بنرها │ ├── followers_liker_bot.py # منطق ربات تعامل با فالووینگ‌ها │ └── post_liker_bot.py # منطق ربات استخراج لایک‌کننده‌ها ├── data/ │ ├── json/ # سشن‌های ذخیره‌شده (Session Cache) │ └── pickle/ # صف کاربران هدف ذخیره‌شده ├── pyproject.toml # تنظیمات استاندارد PEP 621 و uv ├── requirements.txt # لیست پیش‌نیازهای پایتون └── README.md
